# متره‌وبرآوردیار | MetreYar

اپلیکیشن اندرویدی متره و برآورد برای مهندسان عمران، پیمانکاران و دفاتر فنی؛ محصول برند اینجین پلاس (Engine Plus).

## وضعیت پروژه
نسخه آغازین فنی: **1.0.0+1**  
شناسه Android: `ir.engineplus.metreyar`  
واحد پول: تومان  
زبان و رابط کاربری: فارسی، راست‌به‌چپ  
رنگ‌بندی: سرمه‌ای تیره، طلایی و نقره‌ای

## امکانات نسخه پایه
- محاسبه حجم بتن مستطیلی
- محاسبه وزن تقریبی میلگرد بر اساس قطر و طول
- محاسبه مساحت مستطیل
- اجرای آفلاین محاسبات پایه

## اجرای محلی
```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## ساخت APK آزمایشی
با اجرای workflow با نام **Android APK** در GitHub Actions، فایل APK آزمایشی ساخته می‌شود. این خروجی در شروع پروژه امضای انتشار ندارد و برای انتشار در کافه‌بازار یا مایکت باید فرایند امضای امن جداگانه تنظیم شود.

## دقت محاسبات
وزن میلگرد با رابطه تقریبی (d^2/162 	imes L) محاسبه می‌شود؛ قطر بر حسب میلی‌متر و طول بر حسب متر است. این مقدار برای برآورد اولیه است و جایگزین مشخصات سازنده، استاندارد پروژه یا محاسبات مهندس مسئول نیست.

# معماری اولیه

- رابط کاربری: Flutter / Dart
- منطق محاسبات: کلاس‌های مستقل در `lib/core`
- ذخیره‌سازی آتی: SQLite با لایه repository
- گزارش‌گیری آتی: سرویس مستقل PDF و Excel
- درآمدزایی آتی: لایه entitlement مستقل از UI و adapter جدا برای هر فروشگاه

## قواعد مهندسی
- فرمول‌ها خارج از Widget نگهداری شوند.
- برای هر فرمول تست واحد نوشته شود.
- ورودی نامعتبر، صفر، منفی و مقدار غیرمتناهی رد شود.
- واحد هر ورودی و خروجی در رابط کاربری نمایش داده شود.
- نرخ‌های بازار با تاریخ و منبع نگهداری شوند.
